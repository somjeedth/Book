# ห้องประชุมสำนักการเงิน — HTML Mockup

Mockup แบบ HTML/CSS/JS ล้วน (ยังไม่มี backend) ของระบบจองห้องประชุม ทั้งฝั่ง **ผู้จอง** และ **แอดมิน**
สีหลัก `#857654` (น้ำตาลทอง) บนพื้นขาว/ครีม · ฟอนต์ **IBM Plex Sans Thai**

ห้องประชุม 2 ห้อง ชั้น 17 อาคาร ซี.พี.ทาวเวอร์ สีลม · สิ่งอำนวยความสะดวก: จอทีวี, ไวท์บอร์ด, Wi-Fi, ไมโครโฟน/ลำโพง

## จองโดยไม่ต้องสมัครสมาชิก

ผู้ใช้จองได้ทันทีโดยไม่ต้องตั้งรหัสผ่าน เมื่อจองสำเร็จจะได้ **รหัสยืนยันการจอง 6 หลัก** (แสดงบนจอและในอีเมลยืนยัน)
ใช้รหัสคู่กับอีเมลที่ใช้จองที่หน้า `manage.html` (เมนู “จัดการการจอง”) เพื่อดูหรือขอยกเลิกการจอง ระบบสมัครสมาชิกยังใช้งานได้ตามเดิม

## วิธีเปิดดู

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือรันเว็บเซิร์ฟเวอร์แบบง่าย

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ข้อมูลตัวอย่างถูกสร้างอัตโนมัติ (อิงจากวันที่ปัจจุบัน) และเก็บใน `localStorage` ของเบราว์เซอร์
กด **“รีเซ็ตข้อมูลตัวอย่าง”** ที่แถบด้านบนเพื่อเริ่มใหม่

| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| ผู้จอง | somchai@company.co.th | 1234 |
| แอดมิน (สิทธิ์ทั้งหมด) | admin@company.co.th | admin1234 |
| แอดมิน (สิทธิ์จำกัด: Dashboard, รายการจอง, อนุมัติยกเลิก) | staff@company.co.th | staff1234 |

## หน้าจอ

### ฝั่งผู้จอง
| ไฟล์ | รายละเอียด |
|---|---|
| `index.html` | หน้าแรก: สถานะห้องตอนนี้ (เขียว = ว่าง / แดง = ไม่ว่าง) และปฏิทินแบบรายวัน/รายสัปดาห์/รายเดือน ตัวกรองจำนวนคน สิ่งอำนวยความสะดวก และช่วงเวลา |
| `login.html` | เข้าสู่ระบบ / สมัครสมาชิกสำหรับผู้จอง |
| `booking.html` | ฟอร์มจอง (ชื่อ, แผนก, เบอร์โทร, อีเมล, วัตถุประสงค์, วัน-เวลา) ตรวจห้องว่างทันที และไม่ให้จองเวลาที่ทับซ้อนกัน |
| `my-bookings.html` | การจองของฉัน และส่งคำขอยกเลิก |
| `email.html` | กล่องอีเมลจำลอง: ยืนยันการจอง, เตือนล่วงหน้า 1 วัน (มีปุ่มยกเลิก), แจ้งการยกเลิก |
| `cancel.html?token=…` | หน้าขอยกเลิกที่เปิดจากลิงก์ในอีเมล |

### ฝั่งแอดมิน (`admin/`)
| ไฟล์ | รายละเอียด |
|---|---|
| `login.html` | เข้าสู่ระบบสำหรับแอดมิน |
| `dashboard.html` | ภาพรวม: KPI, กราฟการจองรายวัน, สัดส่วนสถานะ, การจองแยกตามแผนก, ช่วงเวลายอดนิยม, ตารางของวันนี้, คำขอยกเลิก, กิจกรรมล่าสุด |
| `bookings.html` | รายการจองทั้งหมด: ค้นหา/กรอง, ดูรายละเอียด, ยกเลิกได้ทันที, ส่งออก CSV |
| `cancel-requests.html` | อนุมัติ/ปฏิเสธคำขอยกเลิก |
| `rooms.html` | จัดการห้อง: ความจุ, สิ่งอำนวยความสะดวก, เปิด/ปิดการจอง |
| `history.html` | ประวัติการจอง (audit log) ละเอียดทุกรายการ ส่งออก CSV ได้ |
| `emails.html` | บันทึกอีเมลที่ส่ง และปุ่มจำลองรอบส่งอีเมลเตือนล่วงหน้า 1 วัน |
| `users.html` | ผู้ดูแลและสิทธิ์: เพิ่มแอดมิน (หรือเลื่อนผู้จองเดิมเป็นแอดมิน), กำหนดสิทธิ์รายคน, ระงับ/เปิดใช้งาน, ถอนสิทธิ์ |

## เงื่อนไขที่ mock ไว้
- ห้องประชุม 1 ความจุ 13 คน (เปิดให้จอง) · ห้องประชุม 2 ความจุ 5–6 คน (ยังไม่เปิดให้จอง แต่แอดมินเปิดได้ที่หน้าจัดการห้อง)
- เวลาทำการ 08:00–18:00 น. จองได้ทีละ 30 นาที ไม่สามารถจองย้อนหลังได้
- ป้องกันการจองซ้ำ: ห้องเดียวกันและวันเดียวกัน ถ้าเวลาเริ่ม < เวลาสิ้นสุดของรายการอื่น และเวลาสิ้นสุด > เวลาเริ่มของรายการนั้น จะถือว่าทับซ้อน
- ผู้จองกดยกเลิกได้ แต่ต้องรอแอดมินอนุมัติ (ระหว่างรอ ห้องยังถูกกันไว้) ส่วนแอดมินยกเลิกได้ทันที
- ทุกการกระทำถูกบันทึกในประวัติ และมีการส่งอีเมล (จำลอง) ตามเหตุการณ์

## โครงสร้าง
```
assets/style.css   ธีมสีและคอมโพเนนต์
assets/app.js      ข้อมูลตัวอย่าง, logic การจอง/ยกเลิก/อีเมล, แถบเมนู
assets/home.js     หน้าแรก (ปฏิทินและตัวกรอง)
```

|---|---|
| Login | เข้าสู่ระบบ (บัญชีทดลอง `admin@demo.com` / `1234`, `lead@demo.com` / `1234`) |
